Fondateur en 2025 du mouvement citoyen #M4VLG militant pour le prolongement de la ligne 4 du métro jusqu'à Villeneuve-la-Garenne, j'ai profité du module d'initiation web en L1 informatique pour concevoir un site web statique de cette initiative qui mobilise usagers et élus. Réalisé en autodidacte exclusivement en HTML5 et CSS3 dans le respect des standards du W3C, ce premier site statique allie apprentissage des fondamentaux du développement web et engagement concret sur le terrain.
